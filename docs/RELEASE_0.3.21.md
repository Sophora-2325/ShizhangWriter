# 0.3.21 · 杂项页布局

- 英文显示名统一为 Shizhang Writer；中文显示名为「拾章写作」。主窗口、提示框、程序产品信息和英文说明同步更新。启动文件改为 `ShizhangWriter.exe`，桌面入口同步更新；内部程序集、配置与数据目录保持兼容。

- 设定里的「杂项」改成总览加就地编辑。顶部用「全书生效」标记，并说明只影响后续生成与检查，不会改写正文。标签仍叫「杂项」，保存按钮仍叫「保存杂项」。
- 宽度够 560 时，文风偏好和内容约束左右并排；更窄时先文风、后规则。诊断信息和保存区始终横跨整页。页面只有一条纵向滚动，没有横向滚动。
- 句长是等宽的三段选择：简短、适中、较长。文风参考先显示真实片段；没有范文时给出简短引导和「添加参考」。点「编辑」展开片段列表，每段只保留「编辑」和「更多」。上移、下移、删除收在「更多」里。第四段起仍默认收起，并标明仅保存。
- 禁止词句、避免表达和替代写法各占一行摘要：标题、条数或默认状态、首条预览。点开后就地编辑，一次只展开一处。展开后能看到数量说明；「留空会恢复内置默认」「不会自动替换已有正文」保持可见，更长的解释从「说明」进入。
- 诊断信息默认收在页面末尾。保存状态和「保存杂项」固定在底部。宽页面状态在左、按钮在右；窄页面状态在上、按钮铺满下一行。
- 调整宽度、切换主题、展开其他区域、保存或进入只读时，不会拆掉正在输入的编辑框，光标和选区保留。展开状态不算未保存更改。同一部作品刷新后仍保持展开；换一部作品回到总览。只读时可以展开、查看和复制。

作品数据、生成规则和保存接口不变。
