## 入口

- **杂项 → 文风偏好**：句长、范文、用词倾向、标点策略。
- **杂项 → 内容与用词约束**：禁写词句、避免使用的表达、替代写法建议。
- **杂项 → 其他**：默认折叠，保留配角自动行动及只读系统信息。
- **人物 → 叙事设置**：人称与视角；时态默认折叠。独立于人物卡片，保存为整部作品的默认值。
- **作品右键 → 作品信息**：独立子窗口，展示封面、书名、题材、基调、受众、有效章节数、定稿数、字数、章节目录和作品位置。

## 保存与边界

杂项、叙事设置和作品信息分别只提交自身已修改的字段。同作品重载时，杂项及叙事设置保留未保存草稿，保存一个入口不会覆盖另一个入口的草稿。

题材、基调、受众保留原来的发布包说明用途，本轮没有新增正文生成接入。用词倾向、标点策略及配角自动行动仍仅保存，界面明确标注尚未参与生成或检查。清空禁用表达、替代写法建议仍会使用默认值。

叙事设置沿用 `style.pov`、`style.tense`，保存时重新编译生成约束。它们不进入章节设定快照；故事流、章节/场景覆盖、视角人物切换和知情范围约束未在本轮实现。

作品信息窗口绑定打开时的作品 ID。打开前先保存主工作区待写入的正文等内容。章节统计排除 superseded，章节目录本轮只读。

重命名沿用现有窗口与文件夹重命名机制，并展示文件夹同步改名提示。重命名前先保存本窗口的资料草稿；改名失败时保留原来的名称，并显示错误。重命名成功属于立即完成的操作，不会因后来取消其他编辑而回滚。

## 封面

项目新增 `cover: { preview, original }`，旧作品缺失此字段时默认无封面。数据库 JSON 与作品文件均保留引用。

封面复用已有的不可变图片资源：文件存放在作品的 `插图/` 目录中，保存相对路径，按内容哈希去重，保留原图与必要的预览。显示使用长边至多 480 像素的解码结果；导入、预览生成、读取均使用后台工作队列。

选择图片先形成窗口草稿，点击保存后更新封面引用。移除或取消只解除/放弃引用，不删除可能被正文或撤销历史使用的图片。未引用的导入资源暂留，未来资源清理必须先核对全部引用。

新增 `PATCH /project/{id}/info`，接受可选的 genre、tone、audience、cover。封面必须是作品目录内现存且扩展名受支持的图片路径；拒绝绝对路径、目录穿越、缺失文件与不完整的资源引用。

作品文件仍通过临时文件和原子替换写入；文件写入失败时，数据库更新随事务回滚。该保护不等同于跨文件系统与数据库的完整崩溃事务。

无作品目录时仍可编辑定位资料，封面选择不可用；目录缺失时窗口保留展示、关闭入口，并提示恢复目录。坏图或缺失封面不阻止查看资料。
