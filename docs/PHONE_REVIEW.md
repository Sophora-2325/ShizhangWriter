# 手机审阅侧栏（0.2.4，2026-10-18）

右侧选项列为“设定／功能／审阅”，共用侧栏；审阅与写作并排，支持弹出正文窗口。顶部阅读按钮已移除，“视图→审阅侧栏”打开相同面板。设定标题简化为“设定”，隐藏继承范围说明，保留继承操作及只读限制。

## 审阅与同步

- 默认逻辑尺寸 360×648，侧栏不足时只缩放外观，文档页宽与页高保持固定。使用 WPF 文档分页，支持左右键、PageUp/PageDown、滚轮及点击页码跳转。
- 覆盖、水平滚动与无动画三种翻页；系统禁用动画时直接切换。目录和查找在辅助菜单中，保留“修改此处”。
- 预览章节独立于编辑章节。目录及上下章只切换预览；定位按钮回到编辑章和光标处，“修改此处”明确切换编辑章。正在查看其他章节时不会被输入强制切回。
- 本章编辑停顿 600ms 后生成预览。`ReadingSnapshot` 递归克隆段落、行内格式、Section/List/Table 和图片；复用像素源或图片缓存。不在作者文档上移除图片、修改 Source 或切换选区，不触发保存和撤销。
- 使用请求版本及作品/章节身份丢弃过期的异步章节结果。重新排版保持阅读锚点，重新打开章节恢复本地阅读位置。

## 设置与声音

独立非模态设置窗口，重复打开激活同一窗口。“外观”支持字号、字体、标题对齐、行距/段距、页边距、宽高、翻页方式和首行缩进。初始字号26，标题居中，边距16；间距系数1对应1.3倍字体行高及一行段间距。旧 reading.json 中字号与行距迁移保留，旧每行字数不再控制页宽。

朗读使用 Windows SAPI，全部 COM 操作运行于独立后台 STA，不调用后端或云服务。支持声音、语速、音量、暂停/继续/停止及可选连读，连读默认关闭。本机未安装语音时提示并禁用播放。当前朗读章修改时暂停并更新快照，保留语句锚点以供继续。换章、隐藏侧栏及开始听写时停止朗读。打开本地声音列表不会开始播放。

## 创作格式

字号、样式、缩进、行距、图片、听写及发布保留在顶部。字体及对齐按钮不再显示；加粗、斜体、下划线、颜色在正文右键菜单的紧凑操作行中，继续支持快捷键。右键图片保留专用菜单，只读时禁用修改。

载入章节时普通正文规范为左对齐，不生成保存请求或撤销步骤；标题、引用及题注保留排版。新段落按当前字符字号缩进两字，Shift+Enter保持段内换行。正常保存时才持久化规范后的格式。

## 验证与发布

- 新增快照不触碰图片/选区/撤销、五万字分页与窄栏不重新分页、原有配置迁移、正文与特殊段落识别、右键格式保留选区、新段字号缩进、后台STA语音和无语音状态测试。
- 临时示例稿的真实主窗口验证：正文未保存时自动更新审阅，编辑章仍保持原值、创作区保持可编辑；浅色/深色审阅和外观/朗读窗口已渲染核对。样例图片不进入源码。
- 实际 Windows 本机声音短句播放已完成。桌面测试统一串行，避免焦点、原生文字输入和全局UI状态的并发干扰。
- 正式入口统一为 dist/wpf/novel-gm.exe，桌面与开始菜单指向该文件；旧 wpf-image-fix、wpf-image-selection 副本同步为同一构建。
