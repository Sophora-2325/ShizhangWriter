# 本章规划分区界面

2026-10-20，包含分区规划界面及后续三张人物简略卡、脉络杂项、剧情约束示意图。人物详细编辑窗口布局保持原样。

- 默认显示剧情大纲、场景核心/剧情约束、冲突点/代价、戏份/人物/脉络、篇幅/留白、杂项六行菜单。细分隔线和居中文字沿用应用主题；不再显示旧自由规划卡、折叠结构化表单或进度条。
- 点击项目就地展开详情，再点当前项目收起；切换不修改草稿。内容宽度至少 704 DIP 时左菜单固定 384 DIP，右侧详情伸展；不足时详情单页显示，顶部可返回菜单。低高度菜单纵向滚动。
- 剧情大纲映射 free_text；场景核心映射 scene_goal；冲突点映射 conflict；代价映射 stakes；留白映射 open_decision_for_user。剧情约束包括 must_include 和 must_not，每行一条。篇幅仍为 target_word_count，保留三个预设和正整数输入；无效输入显示提示，不替换最近有效值。
- 新增 plan.misc 字符串，默认空，作为本章作者补充说明。保存、复制、章节判空和 JSON 持久化均保留该字段；无需数据库结构迁移。AI 规划接收它作为作者提示，重新规划与自动补全表单时保留作者原文，正文生成上下文独立标注该说明；明确清空可正常保存。
- 人物、脉络、戏份详情仅显示本章已加入的名称与移出按钮，底部添加入口固定。选择器多选确认才加入，取消不改变计划；已有项禁用且不重复加入。
- 人物候选优先作品主档并补入本章历史资料；脉络优先本章资料，再补作品主档；同 ID 去重。历史未知 ID、戏份原值保留并可移出；唯一名称可匹配到已有 ID，重名不猜测。
- 人物与脉络选择器保留新建入口，复用现有编辑窗口。新建人物保存至作品主档，设定区与规划使用同一个稳定 ID；随后保存本章关联。关联或刷新失败时在原窗口重试，同一 ID 不重复新建。章节不存在时在确认保存后创建章节，取消窗口不创建空章。
- 加入已有资料时，计划保存会把当前章快照里缺少的相应主档资料补入，确保 AI 能读取。移出计划不删除人物、脉络或当前章设定。新建前保存现有正文/规划草稿，失败阻止继续，异步操作校验原作品与章节身份。
- 普通编辑继续沿用自动保存及失败草稿保护；只读状态仍允许浏览菜单，禁止编辑、添加和移出。弹出与停靠使用原有规划控件，不建立第二份草稿。

## 分项保存与取消

- 剧情大纲、场景核心、冲突点、代价、篇幅、留白、杂项的右侧编辑区增加居中的“保存 / 取消”，保存在左。按钮固定可见，下缘距详情内容区底部约 5%，输入区单独滚动。三类关联列表不增加按钮。
- 剧情约束的上、下编辑区标题行各放一组“保存 / 取消”，分别作用于 `must_include` 与 `must_not`。“必须包含”文案改为“将会出现（每行一条）”，字段名和逐行保存语义兼容原数据。
- 进入某项时记录当时的内容；自动保存不改变取消的恢复起点。取消恢复该项并立即排队保存，不关闭详情、不撤销其他项；切换后重新进入以新的进入值为起点。
- 手动保存成功后，以本次提交值更新恢复起点；失败保留原起点和眼前输入。等待期间可继续输入，迟到结果不能确认随后输入、其他章节或重新进入的编辑会话。正在保存的该项暂时禁用其操作按钮。
- Ctrl+S 在规划区内复用该项保存；约束中仅确认焦点所在组，按钮焦点和点击也记录所在组。没有组目标时只执行原保存。规划区外执行原全局保存，不确认规划项。停靠区与弹出窗口行为一致。
- 只读时禁用操作。篇幅无效时不能手动保存，取消仍可恢复有效起点。保存回调复用主窗口顺序队列并返回成功状态，继续保存正文与评注。

## 人物简略卡与脉络杂项

- 设定区人物简略卡左侧为大幅竖向画像，右侧依次为姓名、年龄、性别；身份留在详细编辑窗口。缺失或损坏画像显示等尺寸占位，长姓名换行，字段支持复制，原编辑、删除和只读行为保留。
- 后续高度反馈已落实：身份区域缩至原 60%，外围间距同步收紧；长姓名自然增高。人物标签不再显示“叙事设置”区块，详见 `CHAPTER_DISPLAY_UI.md`。
- 脉络编辑窗口的“脉络基调”下增加整行“杂项”，右侧多行编辑器铺满剩余空间。切换栏目保留输入，复用窗口保存/取消与失败重试。
- 前后端 `PlotThread.misc` 默认为空；随作品主档、章节设定快照、继承、重新打开保存，显式空串可清空。无需数据库迁移。非空时进入 AI 上下文，标注“脉络补充说明（作者意图，不自动视为已发生事实）”。中、英、日均提供对应文案。
