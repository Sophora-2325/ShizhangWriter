# novel-gm 0.3.15

正文顶部操作条按「写作与浏览优先」重整：单行分组、左对齐，取消原来整条居中、分享图标孤立在最右端的布局；「发布到第三方」移入「更多」，功能区的发布入口保持不变。0.3.14 的工具台继续保留，本轮只动正文顶栏与演示状态。



## 分组与顺序

充足宽度下从左到右：

**专注 ｜ 稿纸/铺满 ｜ 字号 · 正文样式 ｜ 插图 · 听写 ｜ 添加批注 · 历史版本 ｜ 更多**

- 全部使用 16 DIP 单线图标、13 DIP 界面字、3 DIP 圆角；普通操作中性，激活态用浅底 + 细标记。
- 「专注」「稿纸/铺满」直接显示文字；字号提示为「字号（磅）」，12.8 仍是磅值，不改单位。
- 图标按钮补了工具提示、`AutomationProperties.Name` 和键盘焦点；点工具不会清掉正文选区。
- 不再让整条工具栏一起禁用：只读章节仍可专注、切宽度、看历史；编辑类按权限单独禁用。

## 专注

- 临时隐藏主窗左右选项列、左右面板、分栏和对照栏，只留正文；再次点击或按 Esc 恢复。
- 不改变纯净/辅助模式，不关闭已弹出的子窗口，不修改 `_leftTab` / `_rightTab`。
- 进入前的栏位宽度/可见性会快照；`CaptureLayout()` 在专注状态下按快照保存，关闭程序不会把专注布局写进 `layout.json`。
- Esc 优先级：先关「更多」/颜色浮层 → 再退出专注 → 最后才执行原来的“打开设置”。


## 稿纸 / 铺满、批注、历史

- 「稿纸/铺满」直接显示当前模式并切换；复用 `ThemeManager.ApplyBodyWidthMode`，菜单的 `View → 稿纸列` 同步，只改呈现，不改正文、换行或历史。
- 「添加批注」复用 `BodyEditing.CanAddComment` / `AddComment`；没有有效选区时禁用并提示「先选中正文」。
- 「历史版本」复用现有 `VersionsWindow`；打开已有历史不调用模型，保存失败时沿用原有停止逻辑。
- 三个入口都走宿主事件，主窗和弹出正文窗共用 `WireFormatBar` 绑定；子窗不显示「专注」。

## 更多

「更多」是一个常驻浮层，不再用孤立图标：

- 字体、行距、首行缩进、字形（加粗/斜体/下划线）、对齐、颜色；
- 段落设置（复用 `BodyEditing.ShowSpacing`）；
- 正文样式、插图、添加批注、历史版本中任何被窄窗口收起的项；
- 发布到第三方。

浮层用 `StaysOpen=True` 并自己处理外部点击、Esc、窗口失活，避免字体/颜色下拉被父弹层误关。浮层里的控件与工具栏共用同一状态；字号/样式选择器在被收起时才出现，避免同一操作同时显示两套开关。


## 窄窗口与收纳

- 固定保留：专注、稿纸/铺满、字号、听写、更多。
- 按 **正文样式 → 插图 → 添加批注 → 历史版本** 的顺序整项收进「更多」；菜单里保留完整名称。
- 不换行、不横向滚动、不裁切；极窄时进一步收紧内边距和字号列，但录音停止按钮始终可见。
- 420 DIP 自动化布局检查通过；中文和日文窄窗口实测无工具行越界。


## 听写

- 录音时显示红点、时长和独立停止按钮；窄窗口也不会把停止入口收起。
- 转写时显示「正在转写…」，失败时在工具栏内显示原因并自动淡出；不再用语音错误弹窗打断。
- 没有新增语音协议；录音/转写异常、切章和插入目标沿用原有守卫。

## 可用性矩阵

| 控件 | 启用条件 |
|---|---|
| 专注、宽度 | 始终可用 |
| 历史版本 | 有章节且不忙；只读可用 |
| 发布到第三方 | 有作品且不忙；只读可用 |
| 添加批注 | 可编辑且有非空选区 |
| 字号、正文样式、字体/行距/缩进/字形/对齐/颜色、段落设置、插图、听写 | 可编辑且不忙 |
| 更多 | 始终可用，内部条目按上述规则 |
