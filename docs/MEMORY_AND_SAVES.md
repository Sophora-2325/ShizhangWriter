# 正文保存与章节记忆

本次改动围绕五项问题：安全保存、正文修改后的记忆失效、章节时间边界、定稿后提取摘要、历史检索。

## 日常行为

- 修改正文会使本章摘要、事实、状态增量、文风检查、语义审校和计划校验失效。排版调整不触发文本分析失效。
- 旧分析保存在章节元数据的 `stale_results`，不再进入生成提示词。每种分析只保留最近一次过期副本。
- 修改早章会标记后续章节的记忆和计划需要复核，保留后续正文。重新提取可更新记忆；计划需重新规划或由作者保存确认，提示才清除。
- 定稿先保存正文和定稿状态，再自动提取摘要（调用当前模型，可能产生费用）。提取失败不撤销定稿，界面显示失败，可用“本章摘要”重试。
- 生成下一章时默认按顺序补齐缺失/过期摘要；桌面端提供明确使用近期原文继续的选项。原文模式取首章及最近三章，每章最多 6000 字（超长取首尾各 3000 字），不会承诺覆盖全部历史。
- 规划、生成、重写、提取、审校均以目标章节为边界，历史信息只来自更早的未作废章节。人物秘密及事实知情者会明确标注给模型。
- 模型运行期间正文或上下文发生修改时，旧结果不会覆盖新正文，返回 `409 BODY_CHANGED`，需重试。

## 保存和恢复

正文和 JSON 都先在同目录写临时文件、刷新后原子替换。作品文件夹的章节保存使用 `.novel-gm/pending-save.json` 记录待完成操作，按正文、元数据、SQLite、事实文件的顺序推进。改名时旧正文在提交完成后才删除。

启动、读取章节或再次保存时会重放未完成日志；这是“继续完成已记录保存”，不是自动回滚。重放可重复执行。索引数据库损坏或丢失时仍可通过“打开作品文件夹”重建。

正文历史位于 `.novel-gm/history/<文件名哈希>/<正文哈希>.md`，每个文件名保留最近 10 个不同正文版本。文件改名后，原文件名的历史仍保留在原哈希目录。需要恢复时可读取相应 Markdown，再通过正文编辑器保存。历史文件与保存日志随作品备份。

旧版尚未迁移到作品文件夹的作品也使用原子正文写入，但作品日志和历史目录需要先迁移到作品文件夹。原子替换与刷新不构成对硬盘故障的保证，作品 zip 备份仍有用途。

## 版本兼容

SQLite 启动迁移增加 `chapters.freshness_json` 以及事实的 `source_hash`、`embedding_model`，不删除旧数据。正文版本为规范化 CRLF 后的 SHA-256；分析记录对应正文哈希。

旧作品没有版本字段时，以首次读取的正文作为兼容基线，已有摘要继续保留。无法倒推出升级前摘要是否已经过期，重要作品可手动重新提取。新字段随章节 JSON 与 `facts.json` 导入导出。

## 检索配置

默认使用中文双字词元 / 英文词元的 BM25 关键词检索，不联网，不再使用字符哈希向量。配置以下环境变量并重启后端，可启用真正的 Embedding 服务和关键词混合检索：

| 变量 | 内容 |
|---|---|
| `NOVEL_GM_EMBEDDING_URL` | OpenAI 兼容 API 基地址，包含服务需要的 `/v1` 等前缀，不含 `/embeddings` |
| `NOVEL_GM_EMBEDDING_MODEL` | 该服务实际提供的 Embedding 模型名称 |
| `NOVEL_GM_EMBEDDING_API_KEY` | 可选，仅通过环境变量传入，不写入作品或日志 |

例如本地服务基地址可以是 `http://127.0.0.1:8080/v1`；模型名应使用该服务已安装的模型。本功能不自动下载模型，也不自动为聊天模型配置选择 Embedding 模型。

检索先过滤章节边界、正文版本、过期记忆和作废章节，再调用 Embedding 服务。使用归一化余弦相似度与 BM25 的倒数排名融合，人物知情范围作为轻量排序信号；返回来源章节、正文哈希和知情者。知情者标注不会自动证明角色推理符合设定，仍需审校。

服务断连或返回无效向量时降级为关键词检索。离线模式下只允许回环地址的 Embedding 服务，并禁止跟随 HTTP 重定向。地址或模型名改变时旧向量不会混用，按需重建；如果同名模型的内容在服务端被替换，应先清空其缓存向量再重建。

生成时最多补建 64 条事实向量，按每批 32 条发送，单次请求超时 5 秒。完整重建可调用 `POST /project/{id}/memory/reindex`。向量只保存在 SQLite 缓存中，重新导入作品后可重建，不增加独立数据库服务。

回归测试：`services/core/tests/test_memory_lifecycle.py`。覆盖失败保存、日志恢复、正文与排版修改、外部正文修改、上游改稿、时间边界、分析并发冲突、定稿与提取失败、语义检索、模型切换、断连降级及离线限制。
