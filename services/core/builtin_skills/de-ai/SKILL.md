写正文时遵守下面几条。它们只改变表达方式，不得为此删掉伏笔、钩子、人物特征和必要的转折。

**一、不用这些词**（出现就换成具体描写或直接删掉）
- 不禁、不由自主、映入眼帘、心中暗道、眼中闪过一丝、嘴角微扬、勾起一抹弧度、只见、此时此刻、目光如炬、不容置疑、显而易见、仿佛 / 宛如 / 犹如 / 如同（比喻确有必要时，每千字最多一处）。
- 「缓缓、微微、轻轻、淡淡」每千字合计不超过三个，不要给每个动作都垫一个。
- 空泛大词：命运、宿命、注定、前所未有、无尽的、一种说不清的感觉。

**二、不用这些句式**
- 「不是 A，而是 B」及其变体（「与其说……不如说」「不是……不是……而是」）：直接写 B。
- 「……，带着……」万能状语，以及「声音不大，却带着……」：改成独立短句或动作。
- 三连排比、对仗工整的长句，连续几段同一种开头。
- 「他知道……」「她意识到……」「他感到一阵……」：改成能看见的动作、物件和后果。

**三、不解释，不升华**
- 叙述者不跳出来剧透或定性：「她不知道的是……」「这一刻他终于明白……」不写。
- 段尾、章尾不写总结和感悟，停在动作或台词上。
- 不替读者解读台词的潜台词；人物说完话，用动作或沉默接住。

**四、写法**
- 情绪落在身体和物件上：手里的杯子转了几圈，烟烧到了手指才发觉。
- 长短句交替：紧张时短句，舒缓时才放长；不要每段都是四五句、每句差不多长。
- 一个瞬间只写一次，不在相邻两段里把同一个动作拆开重复描写。
- 动作不要写成步骤清单（伸手、拿起、放下、转身……），挑最能说明人物状态的一两个。
- 对话标签用「说」即可，或者干脆省掉；不要句句「沉声道」「冷笑道」「淡淡地说」。
- 口语化的地方就用口语，不要让每个人物都说书面语。
