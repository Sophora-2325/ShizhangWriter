# 关于拾章写作

拾章写作是一款在 Windows 上运行的小说写作工具。你可以自己写，也可以选择模型协助规划、起草、审阅和整理设定。AI 规划先形成草稿，由作者确认采用。

一部作品保存在一个文件夹中，方便备份和移动。API 密钥单独存放在 Windows 凭据管理器；调用云端模型时，相关正文和设定会发送给你配置的服务。软件不附带模型额度，第三方 API 可能产生费用。

当前版本为 **0.3.21**。启动程序为 `ShizhangWriter.exe`；内部标识、配置与数据目录继续沿用 `novel-gm`，兼容原有作品。完整功能和安装说明见 [中文 README](README.md)。

## About Shizhang Writer

**Shizhang Writer** (拾章写作) is a Windows app for writing novels with optional AI assistance. Write manually, or choose a model to help plan, draft, review and maintain story settings. AI planning creates a draft for the author to explicitly adopt.

Each work lives in its own folder for backup and portability. API keys use Windows Credential Manager. Cloud-model requests send the relevant prose and settings to your configured service; API credits are not included.

The current version is **0.3.21**. Launch `ShizhangWriter.exe`; the internal identifier, configuration and data folders remain `novel-gm` for compatibility. See the [English README](README.en.md) for features and setup.
